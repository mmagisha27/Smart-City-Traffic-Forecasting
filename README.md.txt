# Smart City Traffic Forecasting

## Objective
Forecast traffic volume at city junctions using machine learning techniques.

## Dataset
Smart City Traffic Dataset

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn

## Model
Random Forest Regressor

## Evaluation Metric
Mean Absolute Error (MAE)

## Result
MAE: 2.864

## Conclusion
The model successfully predicts traffic volume using historical traffic data and can assist smart city traffic management systems.

## Note

The trained model file (.pkl) is not included in this repository due to file size limitations. The model can be regenerated by executing the notebook.
